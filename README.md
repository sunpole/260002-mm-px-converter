# Конвертер мм и пикселей

Статическое веб-приложение для перевода миллиметров в пиксели и обратно с
настраиваемой плотностью PPI. Подходит для подготовки макетов к печати и
проверки размеров экранной графики.

## Ссылки

- Публичная страница: `https://sunpole.github.io/002-mm-px-converter/`
- Исходный код: `https://github.com/sunpole/002-mm-px-converter`
- Карточка в SUNPOLE HUB: будет добавлена после проверки опубликованной страницы.

## Запуск

Откройте `index.html` в современном браузере. Приложение статическое и не
требует установки зависимостей.

## Версия

Текущая версия — `0.1.0`. История изменений ведётся в `CHANGELOG.md`.

## Состав

- `index.html` — основная страница конвертера.

- `preview.jpg` — исторический скриншот исходной версии.
- `screenshot-2026-09-18.png` — скриншот опубликованной GitHub Pages после проверки.
